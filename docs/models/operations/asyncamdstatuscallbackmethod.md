# AsyncAmdStatusCallbackMethod

The HTTP method we should use when calling the `async_amd_status_callback` URL. Can be: `GET` or `POST` and the default is `POST`.

## Example Usage

```typescript
import { AsyncAmdStatusCallbackMethod } from "twilio-sdk/models/operations";

let value: AsyncAmdStatusCallbackMethod = "GET";
```

## Values

```typescript
"GET" | "POST"
```
