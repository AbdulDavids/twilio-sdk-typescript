# AmdStatusCallbackMethod

The HTTP method we should use when calling the `amd_status_callback` URL. Can be: `GET` or `POST` and the default is `POST`.

## Example Usage

```typescript
import { AmdStatusCallbackMethod } from "twilio-sdk/models/operations";

let value: AmdStatusCallbackMethod = "POST";
```

## Values

```typescript
"GET" | "POST"
```
